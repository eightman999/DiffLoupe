# DiffLoupe for macOS 1.1.0

**WinMerge難民のための、軽くて速いMacのフォルダ比較ツール。**

DiffLoupe は、2つのフォルダを左右に並べて中身の違いをひと目で見つけられる macOS ネイティブアプリです。
フォルダ納品物のチェック、バックアップの突き合わせ、写真フォルダの整理など、
「このフォルダとあのフォルダ、どこが違う?」を素早く確かめたいときに使えます。

外部ライブラリに一切依存しない軽量設計で、ダウンロードして開けばすぐ動きます。

## 1.1.0 の新着

- **画像比較ビュー** — 画像ファイル(png / jpg / gif / bmp / tiff / heic / webp など)の相違は、
  テキスト差分ではなく専用の画像比較で確認できます。**左右並置 / 重ね合わせ(不透明度スライダ) /
  ブリンク / 差分ハイライト** に対応し、寸法・ファイルサイズ・差分ピクセル割合も表示します。
- **オープンソース化(MIT License)** — Free(コア機能)を MIT License で公開しました。
  商用(Pro)コンポーネントは分離しています。

## 主な機能

- **2ペインのフォルダ比較** — 左右のフォルダを選んで再帰的に比較し、各ファイルを
  **一致 / 相違 / 左のみ / 右のみ** に分類してツリー表示します。
- **賢い差分判定** — まずファイルサイズを比べ、サイズが同じものだけ SHA-256 ハッシュで
  中身を厳密に照合。大量ファイルでも高速です(タイムスタンプの違いに惑わされません)。
- **テキストの行差分ビュー** — 相違のあるテキストファイルを選ぶと、行単位の差分を横並びで表示
  (追加=緑、削除=赤、変更=黄でハイライト)。
- **ノイズの自動除外** — `.git` / `.DS_Store` / `node_modules` を既定で除外(設定でオフにも可)。
- **固まらない・止められる** — 1万ファイル規模でも操作中に画面が固まらず、比較はいつでもキャンセル可能。
- **2ペインの状態を記憶** — ウィンドウのサイズと位置を覚えています。
- **画像比較** — 画像ファイルの相違は専用ビューで左右並置 / 重ね合わせ / ブリンク / 差分ハイライト表示。

- **macOS 13 (Ventura) 以降**

## インストール

### 方法A: ディスクイメージ(.dmg)

1. `DiffLoupe-1.1.0.dmg` を開きます。
2. 表示された **DiffLoupe** アイコンを、隣の **Applications** フォルダへドラッグします。

### 方法B: ZIP

1. `DiffLoupe-1.1.0-macOS.zip` を展開します。
2. 出てきた `DiffLoupe.app` を「アプリケーション」フォルダへ移動します。

### 初回起動時の注意(重要)

本アプリは Apple の公証(Notarization)を受けていないため、初回起動時に
「開発元を確認できないため開けません」と表示されることがあります。次のいずれかで起動できます。

- **アイコンを右クリック →「開く」** を選び、ダイアログで再度「開く」をクリック。
- それでも開けない場合は、ターミナルで以下を実行して隔離属性を外してください:

  ```bash
  xattr -cr /Applications/DiffLoupe.app
  ```

## 使い方

1. アプリを起動し、上部の「左フォルダ」「右フォルダ」ボタンで比較したい2つのフォルダを選びます。
2. 「比較」ボタン(⌘R)を押すと走査が始まります。進捗はウィンドウ下部に表示されます。
3. 結果のツリーで、色分けされたステータスを確認します。
4. 「相違」のテキストファイルをクリックすると、右側に行単位の差分が表示されます。
5. 「差分のみ表示」にチェックを入れると、一致したファイルを隠せます。

## 現行ワークツリーの追加実装(次回リリース候補)

この節は、1.1.0配布物の後に実装された現行SwiftUIワークツリーの状態を記録します。
配布用DMG/ZIPはこの差分を含む形ではまだ再生成していないため、下記チェックサムは
1.1.0配布物のままです。

### 比較エンジンと表示

- JSON / XML / CSV / TSVの構造化比較。キー順・属性順・引用符・BOMなどの表記揺れを正規化します。
- Hex比較(16バイト行、ASCII表示、差分バイト強調、8MiB上限と未比較表示)。
- 改行、行末空白、連続空白、大文字小文字を無視する内容比較モード。
- include/exclude glob(`*` / `?` / `**`)と、ソース管理・ビルド・Web/Node.js・macOSメタデータのプリセット。
- リネーム/移動候補検出、文字単位差分、検索、差分行ジャンプ、コンテキスト折りたたみ、
  長い行の水平スクロール。
- 結果ツリーの状態別フィルタと、大文字小文字を区別しない相対パス検索。
- 画像比較の左右表示、重ね合わせ、ブリンク、差分、スライス、ズーム、パン、閾値調整。

### 運用機能

- Gitのブランチ・タグ・任意refを一時スナップショット化して比較。
- 結果項目の左右実体を開く、Finderに表示、絶対パスをコピーするコンテキストメニュー。
- 比較履歴、左右交換、Finderからのフォルダドラッグ&ドロップ、HTML/CSV/JSON/Markdownレポート。
- CLI `diffloupe`。WinMerge系の`/r`、`/r-`、`/or`、`/enableexitcode`等を受理し、
  GUI専用スイッチは安全なno-opまたは進捗抑止へマップします。
- 設定で有効化できるフォルダ変更監視。比較中の変更をまとめ、連続自動再比較は3回で停止します。
- 左右のコピー候補を表示する読み取り専用コピー計画プレビュー。
- base/left/rightを確認する読み取り専用3-way差分。

## 既知の制限

- フォルダ比較は中身をバイト単位で厳密に見るため、**改行コード(CRLF/LF)だけが違う**
  ファイルは「相違」に分類されます(行差分ビューでは違いが見えない場合があります)。
- 差分ビューは UTF-8・32MiB 以下・左右合計 40,000 行までのテキストが対象です。
